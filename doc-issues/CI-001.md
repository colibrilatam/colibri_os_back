## Contexto

El backend no debe entrar en `main` sin validacion automatica. La auditoria pide un pipeline
obligatorio para build, lint, tests y smoke checks.

## Alcance

- Ejecutar `npm ci`.
- Ejecutar `npm run build`.
- Ejecutar lint sin autofix.
- Ejecutar unit tests.
- Ejecutar integration tests y e2e tests.
- Correr migraciones sobre una PostgreSQL temporal.
- Verificar arranque y `GET /health`.

## Criterios de aceptacion

- El workflow pasa en cada PR.
- `main` queda protegido por checks obligatorios.
- Un fallo de build o test bloquea el merge.
- Hay evidencia de logs y artefactos.

## Pruebas negativas

- Romper una prueba o el build y confirmar que el pipeline falla.

## Prioridad

Release blocker.

## Equipo

DevOps / QA / Backend.
